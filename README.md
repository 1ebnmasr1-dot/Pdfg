# من نص إلى PDF

أداة مجانية تعمل من المتصفح مباشرة: الصق نصك (مع العريض والمائل والعناوين والجداول) وحوّله إلى ملف PDF بمقاس A4.

## المميزات
- يحافظ على العناوين والقوائم والجداول والخط العريض والمائل
- دعم كامل للعربية (اتجاه RTL) والإنجليزية
- مقاس A4، النص 18، العناوين 20، الهوامش 1.27 سم
- يعمل بالكامل داخل المتصفح، ولا يُرسل أي نص إلى خادم

## الاستخدام
افتح الرابط، الصق النص، واضغط **تحويل إلى PDF**.

## التشغيل محليًا
نزّل `index.html` وافتحه في أي متصفح. لا يحتاج تثبيت.
